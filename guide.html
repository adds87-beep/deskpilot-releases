DeskPilot

A menu bar app for a Mac that moves between desks. It keeps the Dock on one screen, and it remembers where every window and every Space belongs at each desk so it can put them back.

How it works

DeskPilot does two things, and both are off until you switch them on.

Keeping the Dock on one screen

macOS moves the Dock to whichever screen your pointer last pushed against the bottom of. DeskPilot holds the pointer a couple of points clear of the bottom edge of every screen except the one you chose, so the Dock is never called anywhere else. It prevents the move rather than undoing it, and nothing runs on a timer. "Main display" means whichever screen has the menu bar, so it works at any desk.

Layouts

A layout is a record of one desk: the set of screens attached, every window's screen, position and size, which Space each window is on, the left-to-right order of Spaces on each screen, which Space each screen was showing, and which apps the layout is allowed to move. A layout is only offered when that same set of screens is attached, so a laptop-only layout never appears at the desk.

Applying a layout puts it all back. Windows are moved through the same Accessibility interface a screen reader uses. Spaces have no such interface, so they are dragged back to their screen and their place in the order through Mission Control, which opens briefly and moves the thumbnails the way you would with a mouse. One fixed drag per Space, and each is checked afterwards.

Setting it up

  1. Install. Open the disk image from the Releases page and drag DeskPilot to Applications. Launch it from there. It is signed and notarised, so macOS opens it without a warning. It lives in the menu bar; there is no Dock icon.
  2. Grant Accessibility. The first launch runs a short setup and asks for Accessibility permission. This is required: moving other apps' windows and Spaces is done through macOS's Accessibility interface, and nothing works without it. Open System Settings, Privacy & Security, Accessibility, and switch DeskPilot on.
  3. Choose what runs automatically. Setup asks whether to put your layout back automatically when you change desks, whether to start DeskPilot at login, and whether to stop the Dock moving between screens. Each can be changed later in Settings. You can Skip and do it all from Settings.
  4. Save your first layout. Arrange your windows and Spaces the way you want them at this desk, then choose Save Current Layout… from the menu. Do the same at each desk you use.

If Accessibility is listed as on but DeskPilot still says it is not granted, remove DeskPilot from the list with the minus button and add it again. macOS ties the permission to the exact copy of the app that asked for it.

The menu

Click the DeskPilot icon in the menu bar. The first line names the screens attached right now.

Apply "name"
Runs that layout now. Only layouts saved for the current set of screens are listed. If none are, the menu says so.
Update "name" to current
Re-records that layout from how things are right now. Use it after you have moved things and want the new arrangement kept.
Save Current Layout…
Records a new layout for the current screens. A window opens to name it and choose what it puts back and which apps it may move (see Profiles). Your screens flick through their Spaces for a few seconds while it looks; nothing is moved.
DeskPilot x.y.z is available…
Appears only when a newer build has been published. Opens the Updates tab.
Settings…
Opens the Settings window, described below.
Run Setup Again…
Repeats the first-launch setup.
Quit DeskPilot
Quits. The Dock lock stops with it.

What happens during a run

  1. The screen dims and a panel appears with a 5 second countdown. Nothing is touched until it reaches zero.
  2. Spaces first, if the layout restores them. Mission Control opens and each Space that is on the wrong screen or in the wrong place is dragged once. Each drag is checked afterwards. Expect about ten seconds per Space.
  3. Windows next: each managed window is moved to its saved screen, position and size.
  4. The panel reports what it did and what it could not do, then closes. The same is written to the log.

Stopping. Press Stop on the panel or Command Shift Escape at any moment. It takes effect at once, even mid-drag: the Space in hand is let go off the bar, which leaves it where it started, and Mission Control closes. Nothing else is touched.

Do not move the mouse or type while a run is in progress. The run is driving the pointer.

Settings: Profiles

The list on the left is every saved layout, with the screens it belongs to. Select one to see and change it.

Name
What the menu shows. Edit it here.
Put Spaces back on the right display, in order
Restores which screen each Space is on and their left-to-right order, through Mission Control. This is the one most people want, and it is how a fullscreen app gets back to its screen without leaving fullscreen.
Move apps to their Space
Also moves each app's windows onto the Space they were saved on. This is per app, not per window: all of an app's windows move together, so a layout that had one app's windows on two Spaces cannot be put back exactly. With this off, only windows on the Space each screen is currently showing are placed, and the run reports the rest as not placed.
Re-enter fullscreen for apps that left it
Puts an app back into fullscreen if it was fullscreen when saved and is not now. Doing so rebuilds its Space at the end of the strip, which loses your order, so leave this off and let the first option move the Space instead.
Apps this profile moves
Every app the layout knows about, with how many windows and Spaces it holds for each. Untick an app and the layout never touches it. Apps that are not running are simply skipped. Tick All and Untick All do what they say.
Update to Current
Re-records the selected layout from how things are now. New apps are added, ticked.
Delete
Removes the layout. This cannot be undone.

Applying is deliberately not a button here. Running a layout is a menu action, so editing one can never rearrange your desk by a misclick.

Settings: Dock

Lock the Dock to one display
Turns the pointer hold on. Off, the Dock behaves as macOS normally has it.
Keep the Dock on
Main display follows whichever screen has the menu bar and works at every desk. Pinning a specific monitor only applies at the desk that monitor is plugged into; elsewhere the lock is off.
Move Dock There Now
Walks the pointer to the chosen screen's bottom edge once, to bring the Dock across if it is somewhere else. Only when you press it.

Do not run DeskPilot's Dock lock alongside another Dock-locking app. Both drive the pointer and they will fight.

Settings: General

Detect my desk and apply its layout automatically
Runs the matching layout when a screen is plugged in or unplugged and the resulting set of screens is one you have saved. See Automatic runs.
Open DeskPilot at login
Starts it with your session. The app must be in Applications for this to work.
Permissions
Shows whether Accessibility is granted, with a button to open the right pane of System Settings.
Show Profiles Folder
Opens the folder holding your layouts, settings and the log.

Settings: Updates

Once a day DeskPilot reads its own release list on GitHub. Nothing about you is sent; it is a public list and the app carries no account or key.

This Mac
The version installed.
Recommended
The newest build for everyone. Install appears when it is newer than this one. Go Back appears when you are on a beta ahead of it.
Beta
A newer build with new features, shown only when Offer beta builds is ticked.
Offer beta builds
Tick to be offered betas. Untick to see only recommended builds.
Check Now
Reads the list immediately instead of waiting for the daily check.
Previous versions
Older builds. Go Back to This installs one, if a new build does something wrong. Say what it was.

Installing downloads the disk image, checks it was signed by the same developer as this copy and that macOS accepts it, swaps it into Applications and relaunches. Layouts and settings are kept. When a newer build is published you are told once; after that it is a line in the menu and a button here.

Automatic runs

With Detect my desk on, DeskPilot watches for the set of attached screens to change: something plugged in or unplugged. Starting the app counts as arriving too. Then:

  1. If the new set of screens matches no saved layout, nothing happens. Plugging in an iPad or a projector does nothing unless you have saved a layout for that set.
  2. If it matches, DeskPilot first checks, without touching anything, whether every Space and every managed window is already where the layout says. If so, nothing happens and the log says so.
  3. If something is out of place, the run starts with the usual countdown and Stop.

Rearranging the same screens does not count as arriving. A presentation starting, a resolution change, or the screens dropping and returning on wake are ignored. A second arrival within 30 seconds of a run is ignored as well.

What is stored, and the log

Everything is in ~/Library/Application Support/DeskPilot/, readable only by you:

profiles.jsonYour layouts. These include window titles.
settings.jsonThe switches in Settings.
log.txtEvery run, every Space drag and what the app read on screen, with the time. Capped at a quarter of a megabyte. It never holds a password or a key.

When something goes wrong, send log.txt with the report. Settings, General, Show Profiles Folder opens the folder.

Known limits

  • A Space in Split View cannot be moved or separated. macOS offers no way to do it; DeskPilot never drops a Space onto another, which is how Split View is made.
  • A fullscreen app is moved by moving its Space. Its window is never taken out of fullscreen.
  • All of an app's windows move to a Space together.
  • A window that is on a Space not currently showing cannot be moved unless Move apps to their Space is on. The run reports it as not placed.

When something is off

The menu says no layouts are saved for this setup
A layout belongs to an exact set of screens. An extra screen, including an iPad, makes a different set. Disconnect it, or save a layout for that set too.
It says Accessibility is not granted
See the note under Setting it up: remove and re-add DeskPilot in the Accessibility list.
"not placed" in the run summary
The window was not on a Space that was showing, or the app was not running. The log names each one.
"missing" in the run summary
A fullscreen app in the layout has no Space open right now, or DeskPilot could not tell which app owns a Space. The rest of the layout still ran.
A Space ended up in the wrong place
Send the log. It records where each drag was aimed and where the Space landed.
